# PROVOC – Plataforma de Reconhecimento e Orientação Vocacional

## 🚀 Sobre o Projeto
# Teste Vocacional via Chat com Inteligência Artificial  

Este projeto tem como objetivo desenvolver um teste vocacional interativo baseado em Inteligência Artificial, integrado aos portais institucionais. O sistema será capaz de interagir com os usuários, realizar um mapeamento de interesses e habilidades por meio de perguntas estratégicas e gerar um relatório personalizado, indicando cursos oferecidos pela instituição relacionados ao perfil identificado.  

## 🎯 Objetivo  
Oferecer uma ferramenta inovadora para auxiliar futuros alunos na escolha do curso ideal, promovendo uma experiência personalizada e de fácil acesso diretamente nos portais institucionais.  

## ✨ Funcionalidades  
- Chat interativo para coleta de informações sobre interesses e habilidades dos usuários.  
- Análise das respostas com IA para identificar o perfil vocacional.  
- Geração de um relatório personalizado com sugestões de cursos oferecidos pela instituição.  
- Destaque para cursos específicos da instituição, com informações detalhadas.  

## 🛠️ Tecnologias Utilizadas  
- **Frontend:** React (ou outra tecnologia de interface)  
- **Backend:** Node.js ou Python  
- **Inteligência Artificial:** GPT ou outro modelo de linguagem natural  
- **Banco de Dados:** PostgreSQL, MongoDB ou outro  
- **Plataforma de Hospedagem:** GitHub Pages, Heroku, ou similar
